# SEO Quick Start Guide

## 🚀 Immediate Actions (Do Now)

### 1. Environment Variables
Add to your `.env.local`:
```bash
NEXT_PUBLIC_APP_URL=https://rehabifyhealth.com
NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=YOUR_CODE_HERE
```

### 2. Create OG Image
1. Design a 1200x630px image with RehabifyHealth branding
2. Save as `/public/logos/images/og-image.png`
3. Include:
   - RehabifyHealth logo
   - Tagline: "AI-Powered Physical Therapy Platform"
   - Clean, professional design
   - Brand colors (#005b57)

### 3. Google Search Console Setup
1. Go to https://search.google.com/search-console
2. Add property: `https://rehabifyhealth.com`
3. Verify using HTML tag method:
   - Copy verification code
   - Add to `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` in `.env.local`
4. Submit sitemap: `https://rehabifyhealth.com/sitemap.xml`

### 4. Test SEO Implementation
Visit these URLs after deployment:
- ✅ Robots.txt: `https://rehabifyhealth.com/robots.txt`
- ✅ Sitemap: `https://rehabifyhealth.com/sitemap.xml`
- ✅ OG Image: `https://rehabifyhealth.com/api/og`

### 5. Verify Structured Data
1. Go to https://search.google.com/test/rich-results
2. Test URL: `https://rehabifyhealth.com`
3. Should show:
   - Organization schema ✅
   - WebSite schema with search action ✅

## ⚡ Performance Optimization

### Core Web Vitals Targets
- **LCP** (Largest Contentful Paint): <2.5s
- **FID** (First Input Delay): <100ms
- **CLS** (Cumulative Layout Shift): <0.1

### Quick Wins
- [ ] Compress images (use WebP format)
- [ ] Enable lazy loading for images
- [ ] Minimize JavaScript
- [ ] Use CDN for assets
- [ ] Enable browser caching

## 🎨 On-Page SEO Checklist

For every new page:
- [ ] Unique, descriptive title (<60 chars)
- [ ] Compelling meta description (155-160 chars)
- [ ] One H1 tag with main keyword
- [ ] Logical heading structure (H2, H3, etc.)
- [ ] Alt text for all images
- [ ] Internal links to related pages
- [ ] Mobile-responsive design
- [ ] Fast page load (<3 seconds)
- [ ] HTTPS enabled
- [ ] Canonical URL set
