## Base URL

```text
https://api.physioaroundme.com/v1
```

All paths on these pages are relative to this base URL. The same API is also available at `https://physioaroundme.com/api/v1`. Sandbox and live share both hosts, and the API key decides the environment.

## Authentication

Send your secret key as a bearer token, or in `X-API-Key`:

```http
Authorization: Bearer sk_test_xxx
```

Keys starting with `sk_test_` hit the sandbox, and keys starting with `sk_live_` hit live. Never call the API from a browser or mobile app. See [Authentication](/docs/getting-started/authentication).

## OpenAPI specification

A complete OpenAPI 3.1 document describes every endpoint, schema, error and webhook:

**https://physioaroundme.com/openapi.json**

You can import it into your API client:

- **Postman:** choose **Import**, paste the URL, and Postman creates a collection. Set the collection's authorization to *Bearer Token* with your `sk_test_` key.
- **Insomnia:** choose **Import**, then **From URL**, and paste the URL.
- **Code generators:** any OpenAPI 3.1-compatible generator can build a typed client from the document.

## Response headers

| Header | When | Meaning |
| :--- | :--- | :--- |
| `X-Request-Id` | Every response | Unique request ID, such as `req_5f2c9a1b7d3e4f60a1b2c3d4`. Quote it to support. |
| `X-Rehabify-Environment` | Every response | `sandbox` or `live` |
| `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset` | Every authenticated response | See [Rate limits](/docs/getting-started/conventions#rate-limits). |
| `Retry-After` | `429` responses | Seconds to wait before retrying |
| `Idempotent-Replayed` | Replayed `POST` responses | `true` when the response was replayed for a repeated `Idempotency-Key` |

## Conventions at a glance

- JSON bodies in UTF-8. Unknown request fields are ignored.
- Timestamps are ISO-8601 UTC strings, such as `2026-10-13T09:30:00.000Z`.
- Money is in integer kobo, in fields ending `_kobo`, with `"currency": "NGN"`.
- Lists use `limit` (1–100, default 25) and `cursor`, and return `{ "object": "list", "data": [...], "has_more": ..., "next_cursor": ... }`.
- `POST` endpoints accept `Idempotency-Key`.

Details are in [Conventions](/docs/getting-started/conventions), and every error code is in [Errors](/docs/getting-started/errors).
