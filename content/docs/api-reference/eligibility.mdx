<Callout type="warn" title="Coming soon">Live eligibility and pre-authorisation checks aren't available yet. With a live key, `POST /partners/eligibility` returns `501 feature_not_available`. Only the simulated sandbox preview described below works today. Don't depend on it in production.</Callout>

When it launches, the eligibility endpoint will let HMOs and sponsors check a member's physiotherapy cover before referring them. Until then, refer covered members with `billing_mode: "hmo_direct_billing"` and put your own authorisation reference in `partner_reference` or `metadata`. See the [HMO integration guide](/docs/guides/hmo-integration).

## Sandbox preview

```http
POST /partners/eligibility
```

With a `sk_test_` key, the endpoint returns a simulated result so you can prototype your flow. No HMO is contacted, and the result means nothing outside sandbox.

| Field | Type | Description |
| :--- | :--- | :--- |
| `member_id` | string | The member's ID with their HMO. |
| `hmo_code` | string | Your HMO code, for example `wellahealth`. |
| `requested_sessions` | integer | Number of sessions you want to check. |

Simulation rules:

- Any `member_id` containing `EXPIRED` returns `eligible: false` with `reason: "policy_inactive"`.
- Any other `member_id` returns `eligible: true`, with `approved_sessions` equal to `requested_sessions`.

```js
// Node.js 18+, sandbox key only (save as check-eligibility.mjs)
const res = await fetch("https://api.physioaroundme.com/v1/partners/eligibility", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.REHABIFY_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ member_id: "WH-123", hmo_code: "wellahealth", requested_sessions: 6 }),
});
const check = await res.json();
if (res.status === 501) console.log("Not available in live yet");
else if (!res.ok) throw new Error(`${res.status} ${check.error.code}: ${check.error.message}`);
else console.log(check.eligible, check.approved_sessions, check.reason);
```

```python
import os

import requests

resp = requests.post(
    "https://api.physioaroundme.com/v1/partners/eligibility",
    json={"member_id": "WH-123", "hmo_code": "wellahealth", "requested_sessions": 6},
    headers={"Authorization": f"Bearer {os.environ['REHABIFY_API_KEY']}"},
    timeout=30,
)
if resp.status_code == 501:
    print("Not available in live yet")
else:
    resp.raise_for_status()
    check = resp.json()
    print(check["eligible"], check["approved_sessions"], check["reason"])
```

## What isn't available

- Real-time verification against HMO systems.
- Pre-authorisation codes or tokens. No referral field accepts one.
- Session allowances, co-payments or policy details.

We'll announce the live endpoint in these docs when it's ready.
