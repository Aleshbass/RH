# Sessions API

The Sessions API allows partners to monitor appointment scheduling, therapist arrival/check-ins, and session completion timestamps.

---

## 1. List Patient Sessions

`GET /api/v1/partners/sessions`

### Query Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `referral_id` | `string` | Filter sessions for a specific referral |
| `patient_phone` | `string` | Filter sessions by patient phone number |
| `status` | `string` | `scheduled` \| `in_progress` \| `completed` \| `cancelled` |
| `from_date` | `string` | ISO 8601 start date (e.g. `2026-08-01`) |
| `to_date` | `string` | ISO 8601 end date (e.g. `2026-08-31`) |

### Example Request

```bash
curl "https://api.physioaroundme.com/api/v1/partners/sessions?referral_id=ref_839210aa9" \
  -H "Authorization: Bearer sk_live_99281..."
```
