Gyms, sports clubs and fitness studios can connect injured members with licensed sports physiotherapists. Members get care quickly, and you earn commission on the bookings you generate.

## Option 1: Reception QR code (no code)

Create a [referral link](/docs/guides/no-code-referral-links) and print its URL as a QR code at reception, in changing rooms or on class schedules:

```text
https://physioaroundme.com/r/<public_code>
```

A member with a sprain, joint pain or a training injury scans the code, submits a short form with consent, and chats with Joy on WhatsApp. Create one link per location to compare branches using link stats.

Sample poster copy:

> **Injured during a workout?**
> Scan to get matched with a licensed physiotherapist, in person or by video.
> *Powered by Rehabify Health.*

## Option 2: A button in your member app

Add a "Book physiotherapy" button that opens your referral link in the browser. Opening the link sets a 30-day attribution cookie, so a member who signs up or books on physioaroundme.com within 30 days is attributed to you permanently. The first partner to attribute a member keeps them.

```js
// Node.js 18+ (save as refer-member.mjs)
import { randomUUID } from "node:crypto";

const res = await fetch("https://api.physioaroundme.com/v1/partners/referrals", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.REHABIFY_API_KEY}`,
    "Content-Type": "application/json",
    "Idempotency-Key": randomUUID(),
  },
  body: JSON.stringify({
    partner_reference: "GYM-IKJ-INJ-0193",
    patient: { first_name: "Adaora", last_name: "Eze", phone: "08031234567", city: "Lagos", area: "Ikeja" },
    clinical: { condition: "Hamstring strain", recommended_sessions: 4, referring_clinician: "Coach Femi" },
    care: { preferred_mode: "patient_choice", preferred_contact_channel: "whatsapp" },
    billing_mode: "patient_self_pay",
    consent: { granted: true, method: "member_app_checkbox", captured_at: "2026-10-13T07:30:00.000Z" },
    metadata: { branch: "Ikeja" },
  }),
});
const referral = await res.json();
if (!res.ok) throw new Error(`${res.status} ${referral.error.code}: ${referral.error.message}`);
console.log("Send this to the member:", referral.links.whatsapp_intake_url);
```

## How you earn

You earn commission on **verified paid bookings** by members attributed to you, through the API, your referral link or a WhatsApp referral code. Clicks and sign-ups alone don't earn. Commissions are paid monthly to your verified bank account. Track them with [`GET /partners/commissions`](/docs/api-reference/commercial-and-commissions#list-commissions).
