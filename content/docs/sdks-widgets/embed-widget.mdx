<Callout type="warn" title="Coming soon">The embeddable JavaScript widget isn't available yet. There's no script URL to include, no widget API, and no publishable key to configure. Any snippet claiming otherwise is out of date.</Callout>

## What it will do

The widget will let partners add a Rehabify referral or booking flow to their own website, attributed to them, without building a form or exposing a secret key. It will rely on publishable keys, which are also coming soon.

## What to use today

| Need | Use now |
| :--- | :--- |
| A "Book physiotherapy" button on your site | Link the button to your [referral link](/docs/guides/no-code-referral-links) (`https://physioaroundme.com/r/<public_code>`). It opens a co-branded landing page and attributes the patient to you. |
| A form styled like your own site | Post it to the [public lead endpoint](/docs/api-reference/referral-links#public-lead-capture). It's CORS-enabled and needs no API key. |
| Referrals created from your backend | The [REST API](/docs/api-reference/referrals#create-a-referral) with a secret key, server-side only. |
| A one-tap WhatsApp start for a specific patient | The referral's [WhatsApp deep link](/docs/sdks-widgets/whatsapp-deep-links). |

We'll document the widget here when it launches.
