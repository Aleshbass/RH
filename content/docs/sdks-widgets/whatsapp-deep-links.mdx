# WhatsApp Deep-Links (Zero-Code)

WhatsApp Deep-Links allow partners to fast-track patient intake through Joy AI with **zero technical integration required**.

```
https://wa.me/2348061525811?text=REHAB_REF_{PARTNER_CODE}_{PATIENT_ID}_{CASE_TYPE}
```

---

## URL Structure

| URL Parameter | Description | Example |
| :--- | :--- | :--- |
| `PARTNER_CODE` | Your unique partner identifier | `GEN_HOSP_IKJ` |
| `PATIENT_ID` | Internal patient or MRN number | `MRN-90218` |
| `CASE_TYPE` | Primary condition code | `LOWER_BACK_PAIN` |

### Live Example

```text
https://wa.me/2348061525811?text=REHAB_REF_RELIANCE_HMO_MBR9910_ACL_TEAR
```

---

## How It Works

1. **Click or Scan**: The patient taps the link on an SMS, web app, or scans a printed clinic QR code.
2. **Joy Hand-off**: WhatsApp opens immediately with pre-filled metadata.
3. **Smart Triage**: Joy greets the patient by acknowledging the referral source (*"Welcome! Dr. Johnson from General Hospital referred you for Lower Back Pain recovery."*).
4. **Partner Bonus**: The referring doctor/partner is automatically credited in the Partner Dashboard upon session completion.
