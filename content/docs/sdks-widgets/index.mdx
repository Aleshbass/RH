description: What you can use today without building a UI (WhatsApp deep links and no-code referral links), and which client-side tools are coming soon.

## Available now

| Tool | What it does | Engineering work |
| :--- | :--- | :--- |
| [WhatsApp deep links](/docs/sdks-widgets/whatsapp-deep-links) | One tap opens a WhatsApp chat with Joy that's already linked to a referral through its tracking code. | None. Use the link from the API response. |
| [No-code referral links](/docs/guides/no-code-referral-links) | A co-branded landing page where patients refer themselves, with attribution and stats. | None |
| [Public lead endpoint](/docs/api-reference/referral-links#public-lead-capture) | Post your own website form to a referral link. CORS-enabled, no API key. | A little front-end code |
| [REST API](/docs/api-reference) | Full control from your backend. | Server-side integration |

## Coming soon

These are on the roadmap and **not available yet**. There's no script, package or key to install today.

| Tool | Status |
| :--- | :--- |
| [Embeddable JavaScript widget](/docs/sdks-widgets/embed-widget) | Coming soon |
| [React component package (`@rehabify/react`)](/docs/sdks-widgets/react-component) | Coming soon |
| Publishable (client-side) `pk_` keys | Coming soon. All current keys are secret, server-side `sk_` keys. |

Until they're available, use a referral link for patient-facing flows, or call the API from your own backend. Never put a secret key in a browser or mobile app.
