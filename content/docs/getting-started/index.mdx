## From application to live referrals

<Steps>
<Step title="1. Apply for partner access">

Apply in the [Partner Portal](https://partners.physioaroundme.com). Rehabify reviews your organisation. Once it's approved, you get sandbox access, which includes test API keys and a sandbox webhook endpoint.

</Step>
<Step title="2. Create a sandbox API key">

In the Partner Portal, go to **Developers → API keys** and create a key. Sandbox keys start with `sk_test_`. The full key is shown **once**, so store it in your secret manager straight away. See [Authentication](/docs/getting-started/authentication).

</Step>
<Step title="3. Build and test against the sandbox">

Follow the [Quickstart](/docs/getting-started/quickstart). Then use the [magic phone numbers](/docs/sandbox/testing#magic-phone-numbers) and the [sandbox endpoints](/docs/sandbox/testing) to rehearse every status and webhook event. In sandbox, no real patient is ever contacted.

</Step>
<Step title="4. Request production access">

In the Partner Portal, choose **Request production access** and complete the go-live checklist. Our [Go-live checklist](/docs/api-reference/partner-integration-v1) lists what we look for.

</Step>
<Step title="5. Go live">

Once Rehabify approves production access, create a `sk_live_` key, set your live webhook endpoint and secret, and switch your configuration. Live keys can't be created before approval.

</Step>
</Steps>

## Anatomy of a request

Every API call goes to `https://api.physioaroundme.com/v1` over HTTPS and carries your secret key:

```http title="Request"
POST /v1/partners/referrals HTTP/1.1
Host: api.physioaroundme.com
Authorization: Bearer sk_test_xxx
Content-Type: application/json
Idempotency-Key: 9b2f6c1e-4d7a-4c3b-8e5f-2a1d0c9b8e7f
```

Every response tells you which environment handled the request and gives you an ID to quote to support:

```http title="Response headers"
HTTP/1.1 201 Created
Content-Type: application/json
X-Request-Id: req_5f2c9a1b7d3e4f60a1b2c3d4
X-Rehabify-Environment: sandbox
X-RateLimit-Limit: 10
X-RateLimit-Remaining: 9
X-RateLimit-Reset: 1791883801
```

[Conventions](/docs/getting-started/conventions) covers pagination, idempotency, rate limits, timestamps and money. [Errors](/docs/getting-started/errors) covers every error code.
